# 方法说明

## 1. 研究问题

本项目包含两个相互关联的实验：

1. 复现 IPOP Eu 发射波长 XGBoost 基线，并检查不同划分协议下的泛化差异；
2. 在完全相同的外层折上比较 Eu²⁺/Eu³⁺混合训练与价态专属训练。

第二个实验的主要假设是：Eu²⁺与 Eu³⁺对应不同的电子跃迁机制，将二者混合可能增加不可约的条件异质性；显式分价态建模可能降低预测误差。

## 2. 任务定义

- 回归目标：`Emission max. (nm)`。
- 样本数：1665。
- 标签：Eu 价态 2 或 3，仅来自 IPOP 主表的 dopant valency 字段。
- 主评估模型：XGBoost。
- 基线：训练折目标中位数。

## 3. 特征

IPOP 作者用 SimPL-ML 生成 52 个组成特征。本项目不重新计算这些特征，而是固定使用作者公开的 Eu-only EmP AF 文件。

四种特征组合：

| 名称 | 内容 |
| --- | --- |
| `AF` | 52 个原子属性统计特征 |
| `AF+T` | AF + 温度 |
| `AF+ES` | AF + 激发波长 |
| `AF+T+ES` | AF + 温度 + 激发波长 |

主结果使用 `AF+T+ES`，因为它包含论文强调的测量条件。所有缺失数值只在训练折内使用中位数填补，避免测试信息进入训练。

## 4. XGBoost 配置

固定参数：

- objective：`reg:squarederror`
- tree method：`hist`
- random state：42
- n_jobs：1

内层搜索包含四组预注册候选：

| n_estimators | max_depth | learning_rate | subsample | colsample_bytree | reg_lambda |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 300 | 3 | 0.05 | 0.8 | 0.8 | 1.0 |
| 600 | 3 | 0.03 | 0.8 | 0.8 | 1.0 |
| 300 | 5 | 0.05 | 0.8 | 0.8 | 1.0 |
| 600 | 5 | 0.03 | 0.8 | 0.8 | 5.0 |

选择指标为内层交叉验证 MAE。没有通过更换随机种子或扩大搜索空间筛选更好结果。

## 5. 嵌套交叉验证

- 外层：5 折，用于无偏性能估计；
- 内层：3 折，只在外层训练数据中选择超参数；
- seed：42；
- 分组协议的内层 CV 使用与外层相同的分组键。

外层协议：

### `random_row`

普通随机 KFold。它最接近论文初步 ML 结果，但相同或相似材料系列可能跨越训练和测试集，因此主要表示已见分布附近的插值能力。

### `group_formula`

完整 Formula 不跨折，测试模型面对未见名义配方的能力。

### `group_host`

Host 字符串不跨折，更接近新 host 外推。但不同 host 字符串仍可能属于相同化学家族。

### `group_reference`

同一来源文献不跨折。它阻断同一论文中共享合成流程、仪器和系列变量的相关记录，测试跨文献迁移。6 条 DOI 归属有歧义的记录在该协议中从训练和测试同时排除。

## 6. 价态比较

### Pooled

Eu²⁺与 Eu³⁺样本合并训练一个模型，与原论文的处理一致。

### Separate

在每个外层训练折内：

1. 仅用 Eu²⁺训练一个模型；
2. 仅用 Eu³⁺训练另一个模型；
3. 分别预测测试折中的对应价态；
4. 合并两类 OOF 预测计算总体指标。

两种模式共享完全相同的外层样本和折号。每个拟合模型使用相同的候选参数网格和内层 CV 协议。

注意：Separate 使用两个独立模型，因此比较同时改变了价态分组和总模型容量。它回答的是“价态专属建模策略是否有效”，不是“加入一个价态特征的纯因果效应”。

## 7. 指标

- MAE：平均绝对误差，单位 nm；
- RMSE：均方根误差，单位 nm；
- R²：决定系数。

报告给出五个外层折指标的均值和样本标准差（ddof=1）。折间标准差不是单条材料预测的不确定性区间。

差值方向：

- `r2_change = separate − pooled`；
- `mae_change = separate − pooled`；
- `mae_improvement = pooled − separate`。

## 8. 公平性和完整性检查

- pooled/separate 的 `row_id`、fold、价态和 `y_true` 必须逐行一致；
- 每个协议、特征集、模型和折的训练/测试行数必须一致；
- 强制分组键的训练/测试重叠必须为 0；
- 价态必须严格为 2 或 3，且两类都存在；
- 输出目录在运行期间包含 `.incomplete`；失败时清除陈旧结果；
- 报告器拒绝读取不完整或无法配对的实验。

## 9. 方法边界

当前模型没有使用结构、局域配位、占位、缺陷、完整光谱或材料合成条件。结果支持价态变量的重要性，但不能解释微观发光机制，也不能代替实验验证。
